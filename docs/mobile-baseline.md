## 已知的量測限制

- 手勢、下拉重新整理、觸覺回饋無法在自動化環境驗證。
- 自動化分頁無法捲動最上層文件，頁面捲動相關行為只能靠 iframe 量。
- 無法偽裝 User-Agent，iOS 專屬分支只能靠單元測試涵蓋。
