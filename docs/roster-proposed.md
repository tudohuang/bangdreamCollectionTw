# 名冊補完提案

`docs/roster-proposed.tsv` —— 名冊缺的 15 個人，我能查證到多少就填多少。

## 先講怎麼用

**不要整份直接貼。** 最後一欄「把握程度」是給你看的，貼進 Sheet 之前要刪掉。

1. 打開 `docs/roster-proposed.tsv`
2. 把「高」的那幾列直接貼進「名冊」分頁（記得刪掉最後一欄）
3. 「中」與「低」的自己確認過再貼
4. `npm run snapshot` 更新本機副本 → `npm run health` 確認

## 為什麼不直接寫進去

名冊的角色會顯示在詳情頁的「飾 ⃝⃝」上。填錯的話站上會出現一個
看起來很肯定的錯誤 —— 那比留白糟糕得多。

這跟場館城市那次是同一條規矩（`src/data/venues.js` 開頭寫的
「只放我有把握的」，`tests/utils.test.mjs` 在守它）。我上次違反過一次，
測試擋下來了，這次不再犯。
