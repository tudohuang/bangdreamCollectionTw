# 心得

一場活動一個檔案，檔名就是圖鑑編號：`042.md` 對應 `#042`。
`npm run impressions` 會把這裡的內容折進 `src/data/events.json`，網站就吃得到。

```markdown
---
一句話: 表演神，其他全爛。
---

開場前排隊就知道今天會出事……

## 表演

支援 **粗體**、*斜體*、`行內碼`、[連結](https://example.com)、
清單、`>` 引言、`##` 小標、`---` 分隔線。
```

只有 `一句話`、只有正文，或兩個都有，都可以。
兩個都空的檔案會被當成「待補」跳過，不會覆蓋既有內容。

> **檔名綁的是編號，不是活動。**
> 在 Sheet 中間插一列並重編號，這裡的檔案就會對到別場活動。
> 編號請只往後加，不要重排。

## 為什麼不寫在 Google Sheet

心得是幾百字的文章，塞進試算表的一個儲存格既難寫也難改 ——
這就是為什麼 59 場活動至今一篇心得都沒有。
資料維護留在 Sheet，長文回到編輯器，各自做擅長的事。
